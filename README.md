# 時間価値家計簿

使ったお金を「何時間分の労働か」で見る、スマホ向けの家計簿です。

## できること
- 収入・支出を記録し、今月の合計・収支の差額・予算の残りを表示
- 使ったお金と予算の残りを、自分の時給（手取り）で「労働◯時間◯分」に換算
- 使いみちをジャンル別の円グラフで表示（食事・住まい・暮らし・移動・楽しみ・健康・学び・その他）
- 使う項目を設定で選べる
- ヘルメットをかぶった謎のキャラクター「レオナルド」（通称レオ）が、記録に返事をしてくれる（5回記録するごとにレベルアップして、マントや王冠で少しずつ成長）
- iPhone の「ショートカット」アプリと組み合わせると、Apple Pay のタッチ決済から金額とお店の名前を自動入力（テスト段階）

## プライバシー
- 記録と設定は、使っている端末のブラウザの中（localStorage）だけに保存します。
- サーバーへの送信、会員登録、外部サービスへの接続はありません。
- タッチ決済からの受け渡しは、アドレスの `#` より後ろを使うため、公開先のサーバーには送られません。

## 使い方
1. ページを開き、いちばん下の「設定」で時給・1か月の予算・使う項目を選んで保存します。
2. お金を使ったら、金額を入れて項目を選び「記録する」を押します。
3. 「使いみちの内訳」で、何にいくら・何時間分使ったかを確かめます。

iPhone のタッチ決済とつなぐ手順は、ページ内の「使い方」に書いてあります。

## 仕組み
- HTML・CSS・JavaScript の1ファイル（`index.html`）だけで動きます。外部のライブラリやフォントは使っていません。
- アイコン（`icon.png`）もこのために作成したものです。

## 注意
- テスト段階です。タッチ決済との自動連携は iPhone のみです。
- ブラウザのデータを消すと、記録も消えます。
